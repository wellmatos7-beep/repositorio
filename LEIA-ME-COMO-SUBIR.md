# Como subir as correções (você perdeu o acesso ao git, faça pelo site do GitHub)

Você está sem acesso ao git, então suba pelo navegador:

1. Abra https://github.com/wellmatos7-beep/repositorio
2. **Enviar pasta assets/**:
   - Clique em `Add file` > `Upload files`
   - Arraste a pasta `assets/img/...` inteira desta entrega
   - Commit: `Organiza fotos no padrão Livros`
3. **Substituir arquivos**:
   - Abra `galeria.html` no GitHub > lápis (Edit) > apague tudo > cole o conteúdo de `galeria.html` desta entrega > Save
   - Faça o mesmo para `livros.html` (capa quebrada corrigida) e `index.html`
   - Se usa a página dos caminhões, substitua `Caminhões-de-Hitler-em-no-Brasil.html` também
4. Confira em https://wellingtonmatos.com.br/galeria e /livros (leva 1-2 min para atualizar)
